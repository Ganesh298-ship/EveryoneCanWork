# EveryoneCanWork

An accessible resume builder designed to help everyone create a resume easily.

## Version 1 — Basic Resume Builder

### Features
- Enter personal details and education.
- Add skills, work experience, and projects.
- Preview the resume.
- Print or save the resume as a PDF.

## Technologies
- HTML
- CSS
- JavaScript
- Python

## Project Goal
Make resume creation simple and accessible to people of all educational backgrounds.

## Development Journey
- Version 1: Basic resume builder completed.
- Version 2: Improved design and usability — planned.
- Version 3: Accessibility and language support — planned.
